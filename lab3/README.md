# Лабортаорная работа №3

## Задание

Необходимо:

- на входном языке nuXmv разработать конечно-автоматную модель системы
- на входном языке nuXmv разработать спецификации свойств с помощью LTL- и/или CTL-логики зафиксировать значения параметров и провести верификацию системы и выяснить, выполняются ли все требуемые свойства исходной системы
- если какие-то свойства не выполняются, то необходимо модифицировать параметры и повторно запустить верификацию.
- в итоге необходимо определить граничные значения параметров, при которых система соответствует спецификации

## Условия

Почтовое отделение
При входе на посту клиентам выдаются талончики. Клиент выбирает услугу: получить посылку и отправить посылку. После K минут ожидания клиент уходит.
В почтовом отделении N окон, отправка посылки занимает 3 минуты, получение посылки - 2 минуты. После обслуживания клиента работник выбирает очередного клиента из одной из двух очередей.
Необходимо реализовать несколько процедур обслуживания: например, клиент берется из случайной очереди, клиент берется из очереди, в которой клиент дольше ждет и т.п.
Проверять надо свойства:

ни один клиент не уйдет
ни одна из очередей не превысит длину M
клиент, пришедший раньше, будет обслужен раньше
