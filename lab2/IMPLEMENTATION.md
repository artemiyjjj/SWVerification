# Реализация метрик Чидамбера и Кемерера для Python

## Выполненные задачи

### 2.1. Построение модели программы

Реализован модуль `ck_metrics.py`, который строит модель программы на основе AST (Abstract Syntax Tree) Python. Модель включает:

- **Классы** (`ClassModel`): информация о классах, их методах, атрибутах и базовых классах
- **Методы** (`Method`): информация о методах, используемых атрибутах и вызываемых методах
- **Модель программы** (`ProgramModel`): общая модель со всеми классами и иерархией наследования

Модель строится путем обхода AST и извлечения:
- Определений классов (`ast.ClassDef`)
- Определений методов (`ast.FunctionDef`)
- Обращений к атрибутам (`ast.Attribute`)
- Вызовов методов (`ast.Call`)
- Иерархии наследования

### 2.2. Реализация алгоритмов вычисления метрик

Реализованы все 6 метрик Чидамбера и Кемерера:

1. **WMC (Weighted Methods per Class)** - количество методов в классе
2. **DIT (Depth of Inheritance Tree)** - глубина дерева наследования
3. **NOC (Number of Children)** - количество прямых потомков
4. **CBO (Coupling Between Objects)** - связность между объектами
5. **RFC (Response For a Class)** - ответ класса на сообщение
6. **LCOM (Lack of Cohesion of Methods)** - недостаток связности методов

### 2.3. Отображение метрик

Реализован модуль `metrics_display.py` с возможностями:

- **Сводная таблица** - компактное представление всех метрик для всех классов
- **Детальное отображение** - подробная информация по каждому классу
- **Экспорт в CSV** - сохранение результатов для дальнейшего анализа

### 2.4. Тестовые программы

Создано 5 тестовых программ, демонстрирующих корректность работы модуля:

1. **test_simple.py** - простой класс без наследования
   - Демонстрирует базовые метрики WMC, RFC, LCOM

2. **test_inheritance.py** - иерархия наследования
   - Демонстрирует метрики DIT и NOC
   - BaseClass → Child1, Child2 → GrandChild

3. **test_coupling.py** - связность между классами
   - Демонстрирует метрику CBO
   - Классы ClassA, ClassB, ClassC взаимодействуют друг с другом

4. **test_cohesion.py** - связность методов
   - Демонстрирует метрику LCOM
   - HighCohesionClass (низкий LCOM) vs LowCohesionClass (высокий LCOM)

5. **test_complex.py** - комплексный пример
   - Демонстрирует все метрики одновременно
   - Иерархия Vehicle → Car, Motorcycle → SportsCar
   - Взаимодействие с классом Engine

## Примеры результатов

### test_inheritance.py:
```
Класс                  WMC   DIT   NOC   CBO   RFC   LCOM
BaseClass                3     0     2     0     3      1
Child1                   3     1     1     0     4      1
Child2                   2     1     0     0     3      0
GrandChild               2     2     0     0     3      0
```

**Проверка:**
- BaseClass: DIT=0 (корневой класс), NOC=2 (Child1, Child2) ✓
- Child1: DIT=1 (наследуется от BaseClass), NOC=1 (GrandChild) ✓
- GrandChild: DIT=2 (наследуется от Child1, который наследуется от BaseClass) ✓

### test_cohesion.py:
```
Класс                  WMC   DIT   NOC   CBO   RFC   LCOM
HighCohesionClass        6     0     0     0     6      0
LowCohesionClass         6     0     0     0     7      9
```

**Проверка:**
- HighCohesionClass: LCOM=0 (высокая связность, методы используют общие атрибуты) ✓
- LowCohesionClass: LCOM=9 (низкая связность, методы используют разные атрибуты) ✓

## Ограничения

1. **CBO** - определение связности основано на явном использовании классов в коде. Для более точного определения требуется анализ типов.
2. **Динамические атрибуты** - атрибуты, создаваемые динамически (не через `self.attr = value`), могут быть не обнаружены.
3. **Множественное наследование** - обрабатывается, но DIT вычисляется как максимальная глубина по всем базовым классам.
