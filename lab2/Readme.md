# Лабораторная работа 2

1. Входные данные
1.1. Каждому студенту выдается один объектно-ориентированный язык программирования (С++, Java, Kotlin, C#, Rust, Python и т.п.)
Можно в качестве языка программирования взять тот же язык, который был в первой лабораторной работе.
1.2. Каждому студенту выдается набор 4-6 метрик из списка
метрики Чидамбера и Кемерера (основные или дополнительные)
метрики Лоренца и Кидда
метрики Ф. Абреу
2. Для выбранной пары язык - система метрик необходимо:
2.1. Реализовать построение модели для программы на целевом языке. Можно воспользоваться моделью, построенной в первой лабораторной работе.
2.2. Реализовать алгоритмы вычисления выбранных метрик и отображение их в любом удобном  виде.
2.3. Подготовить набор тестовых программ на целевом языке, которые демонстрируют корректность разработанного модуля подсчета метрик.
