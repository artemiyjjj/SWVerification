# Модуль вычисления метрик Чидамбера и Кемерера (CK Metrics)

## Описание

Данный модуль реализует вычисление метрик Чидамбера и Кемерера для программ на языке Python. Метрики используются для оценки качества объектно-ориентированного кода.

## Реализованные метрики

### 1. WMC (Weighted Methods per Class)
**Взвешенное количество методов в классе**

Количество методов, определенных в классе. В простом случае вес каждого метода равен 1.

**Интерпретация:**
- Низкое значение (< 10) - класс простой, легко поддерживать
- Высокое значение (> 20) - класс сложный, может требовать рефакторинга

### 2. DIT (Depth of Inheritance Tree)
**Глубина дерева наследования**

Максимальная длина пути от класса до корня иерархии наследования.

**Интерпретация:**
- DIT = 0 - класс не наследуется от других классов (кроме object)
- Высокое значение (> 5) - глубокая иерархия, может усложнить понимание

### 3. NOC (Number of Children)
**Количество прямых потомков**

Число классов, которые напрямую наследуются от данного класса.

**Интерпретация:**
- NOC = 0 - класс не имеет потомков
- Высокое значение (> 5) - класс может быть слишком общим

### 4. CBO (Coupling Between Objects)
**Связность между объектами**

Количество классов, с которыми связан данный класс через использование их атрибутов или методов.

**Интерпретация:**
- Низкое значение (< 5) - класс слабо связан с другими
- Высокое значение (> 10) - сильная связность, сложнее тестировать и поддерживать

### 5. RFC (Response For a Class)
**Ответ класса на сообщение**

Количество методов, которые могут быть вызваны в ответ на сообщение классу. Включает методы самого класса и методы, вызываемые из методов класса.

**Интерпретация:**
- Низкое значение - класс имеет ограниченный набор ответов
- Высокое значение - класс может быть слишком сложным

### 6. LCOM (Lack of Cohesion of Methods)
**Недостаток связности методов**

Мера того, насколько методы класса используют общие атрибуты. Вычисляется как разность между количеством пар методов без общих атрибутов и пар с общими атрибутами.

**Интерпретация:**
- LCOM = 0 - высокая связность, методы используют общие атрибуты
- Высокое значение - низкая связность, класс может быть разделен на несколько классов

## Структура проекта

```
lab2/
├── ck_metrics.py          # Основной модуль с моделью и вычислением метрик
├── metrics_display.py      # Модуль отображения метрик
├── main.py                 # Главный скрипт для запуска анализа
├── test_simple.py          # Тест 1: Простой класс
├── test_inheritance.py     # Тест 2: Иерархия наследования
├── test_coupling.py        # Тест 3: Связность между классами
├── test_cohesion.py        # Тест 4: Связность методов
├── test_complex.py         # Тест 5: Комплексный пример
└── run_tests.py            # Скрипт для запуска всех тестов
```

## Использование

### Анализ одного файла

```bash
python main.py test_simple.py
```

### Анализ нескольких файлов

```bash
python main.py test_inheritance.py test_coupling.py test_cohesion.py
```

### Запуск всех тестов

```bash
python run_tests.py
```

## Тестовые программы

### test_simple.py
Демонстрирует базовые метрики для простого класса без наследования.

**Ожидаемые результаты:**
- WMC = 4 (4 метода)
- DIT = 0 (нет наследования)
- NOC = 0 (нет потомков)

### test_inheritance.py
Демонстрирует метрики наследования (DIT, NOC).

**Ожидаемые результаты:**
- BaseClass: DIT=0, NOC=2
- Child1: DIT=1, NOC=1
- GrandChild: DIT=2, NOC=0

### test_coupling.py
Демонстрирует связность между классами (CBO).

### test_cohesion.py
Демонстрирует связность методов (LCOM).

**Ожидаемые результаты:**
- HighCohesionClass: низкий LCOM
- LowCohesionClass: высокий LCOM

### test_complex.py
Комплексный пример, демонстрирующий все метрики одновременно.

## Экспорт результатов

Результаты автоматически экспортируются в файл `ck_metrics.csv` для дальнейшего анализа.

## Требования

- Python 3.7+
- Стандартная библиотека Python (ast, csv, os, sys)

## Примечания

1. Модель программы строится на основе AST (Abstract Syntax Tree) Python
2. Обработка наследования учитывает только явно указанные базовые классы
3. CBO вычисляется на основе использования классов в методах
4. LCOM вычисляется на основе использования атрибутов класса методами
